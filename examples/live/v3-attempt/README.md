# 归档：v3（第二次外部复查修复后的第一次运行）

这批运行使用的是根据第二次外部复查（Codex + DeepSeek）修改后的第一版闸门和断言。它暴露了修复本身引入的问题，修正后又重跑了一次，最终结果见 [examples/live/](../report.md)。本目录下的报告都已按当前（v4）断言重新判定，没有重跑模型。

| 内容 | 按 v4 断言重新判定 | 说明 |
|---|---|---|
| `C*.output.json` / `C*.trace.md`，[report.md](report.md) | 11/11 | 主评测全部通过 |
| [stability/](stability/report.md) | 8/9 | C04 第 3 次以 `incomplete` 结束（见下） |

发现的两个问题：

1. **闸门误伤（C04 稳定性第 3 次）**：v3 新增的中文数字换算把答案中的“同一天 / 哪一天”这类说法当成了“1 天”，闸门连续 3 次以“答案中的数值‘1 天’在所引用的原文中找不到”退回。由于退回信息只给出换算后的“1 天”，模型无法在自己的答案里定位到它，最终因闸门连续退回而以 `incomplete` 结束。修复：前面是“同、哪、某、每、第”等字的单个“一 / 两”不再换算；退回信息附上答案中的原始写法；被退回的提交在执行记录中附上答案片段（v3 记录里没有这个字段，所以这里无法展示当时的原文）。
2. **断言误判（C10 稳定性第 2 次，第四次断言误判）**：模型输出了字面的 `\n`（转义了两次），断言按“第一行”取结论时把整段答案都算了进去，误判为失败。模型的结论“有水印”是正确的。修复：断言和主循环都把字面的 `\n` 当作换行；按修正后的断言重新判定，这次运行通过。

详见 [docs/03-evaluation.md](../../../docs/03-evaluation.md) 第 4 节。
