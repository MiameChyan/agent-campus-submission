| 内容 | 说明 |

v1 → v2 的变化（起因是外部评审指出的两个问题，详见 [docs/03-evaluation.md](../../../docs/03-evaluation.md)）：

1. 提交闸门：引文必须逐字匹配（不再忽略空格）；新增数值事实核对，答案中的业务数值必须能在所引用的原文中找到。
2. 提示词：冲突无法查证时说明还缺什么信息，不给出“确认前先按某一方执行”的临时建议。
3. C02 / C04 断言：只接受 `conflict_needs_confirmation`，要求双方原文引用、冲突描述与资料缺口，并拦截选边建议。
